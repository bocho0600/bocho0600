## About

I build localisation, mapping and navigation systems for robots in GPS-denied, unstructured environments. I currently work on an autonomous mining haul-truck fleet at Decoda, and lead autonomy development for QUT's rover team (ROAR), whose HOUSECAT autonomy stack won 1st place in Autonomy and the Caterpillar Autonomy Award at the NASA SSERVI International Lunabotics Championship 2026.

## Selected Projects

- **[HOUSECAT navigation stack](https://github.com/ROAR-QUTRC/perseus-v3/tree/feat/autonomy-refactoring/software/ros_ws/src/nav-stack)**: GPS-independent ROS 2 navigation for the Perseus rover. LiDAR-inertial odometry, stereo VO and IMU fused in an EKF, with Nav2 (Theta*, RPP), behaviour-tree mission control and ArUco localisation.
- **[Perseus simulation](https://github.com/bocho0600/perseus_simulation/tree/feature/lunabotics-arena)**: Gazebo simulation of the Lunabotics and ARC arenas, with custom plugins for skid-steer slip, diggable regolith and the Livox Mid-360 scan pattern.
- **Atlas-v1**: Mini rover on ROS 2 Jazzy (Jetson Orin, Raspberry Pi) with a custom `ros2_control` hardware plugin for ST3215 serial-bus servos, a rosbridge and React dashboard, and stereo visual odometry with ORB-SLAM3. Reproducible with Nix and devenv, with CI builds cached in Cachix.
- **[QuadROS](https://github.com/bocho0600/ros2-quadro)**: ROS 2 ground control and simulation framework for quadcopters.
- **[Quadro Autopilot](https://github.com/bocho0600/quadro-quadcopter)**: Custom flight controller board (ESP32 + IMU) and firmware, with PID and Kalman filter control.
